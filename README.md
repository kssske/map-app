# Map App

地図上に位置情報付きの投稿を登録・閲覧できるWebアプリです。

## 機能

- ユーザー登録・ログイン（JWT認証）
- 地図上への投稿登録
- 投稿一覧表示
- Mapboxによる地図表示
- PostgreSQLによるデータ保存

## Tech Stack

### Frontend
- React
- TypeScript
- Vite
- Mapbox GL JS

### Backend
- Node.js
- Express
- JWT

### Database
- PostgreSQL

### Deployment
- Vercel
- Railway
